# 运行说明

## 前置条件

- `D:\deepseek-harness` 已安装 DSH 运行时。
- `D:\dsh-股票\quant\.venv` 已安装 qlib、AkShare、LightGBM 和 MCP SDK。
- `D:\dsh-股票\quant\qlib_data\akshare_data` 存在有效 Qlib provider。

## 启动 DSH

```powershell
& 'D:\dsh-股票\bin\start-stock-assistant.ps1'
```

启动时使用 `D:\dsh-股票\.dsh` 作为 `DSH_HOME`。preset 文件是 `D:\dsh-股票\.dsh\.agent-presets\stock-advisor\agent.cordis.yml`，股票 Skill 是该目录下的 `skills\stock-research\SKILL.md`。

## 手动运行

```powershell
& 'D:\dsh-股票\bin\run-research.ps1' -Mode daily -AssetScope all
```

省略 `-Symbols` 时，研究入口使用 `D:\dsh-股票\quant\data\universe.json` 中的完整目录；指定代码时只研究指定标的。Python 固定入口为 `D:\dsh-股票\quant\scripts\run_assistant_research.py`。它输出一行 JSON；失败返回非零退出码。

## 代码池和刷新

`universe.json` 由 AkShare 在线目录发现生成，分别记录股票、场内 ETF 和场外基金的代码、名称、交易所和来源。当前验收快照（2026-08-26）包含：

- 股票：`5,550`
- ETF：`1,587`
- 场外基金：`23,907`

研究刷新会按目录抓取各类标的，并把每个成功或失败代码保存在运行目录的数据事实中。股票使用后复权日线，ETF 使用前复权日线，场外基金使用单位净值序列。每个标的都会检查字段、日期重复、价格或净值、流动性、复权/净值来源和数据新鲜度。

抓取脚本的 `--limit` 只用于验收或小样本排障；它会把目录标记为非完整，避免后续研究把未抓取代码误当成已覆盖。生产全量运行不要传入 `--limit`。

全市场刷新不会一次性创建数万条网络任务。抓取器使用 `quant\data\fetch_state.sqlite3` 保存每个标的的成功日期、失败重试时间和租约，按有限批次领取任务；每次运行只消耗配置的时间预算，下一轮从上次成功日期之后继续。单标的请求有连接/读取超时、指数退避和进程内限速，写入 CSV 使用临时文件替换，崩溃后会回收过期租约。

完整 `all` 研究请求通过后台 worker 入队并立即返回 `job_id`，不会占用 MCP 请求直到全市场下载完成。使用 `get_run_status` 查看 `coverage`、`pending`、`failed`、`stale` 和当前阶段；全市场刷新要求覆盖率至少达到配置的 `min_universe_coverage`（当前为 `0.93`），明确失败的抓取子进程仍会阻止发布。全市场任务可按覆盖率比例容忍少量过期数据，定向任务发现任何过期标的都会阻止发布。只有数据覆盖和研究门槛都通过，才会更新 `current.json`。重复提交同一研究范围会复用仍在进行的任务。

## 查看结果

- 当前成功结果：`D:\dsh-股票\quant\results\assistant\current.json`
- 运行目录：`D:\dsh-股票\quant\results\assistant\runs\YYYY\MM\DD\<run_id>`
- 运行日志：`D:\dsh-股票\quant\logs`
- DSH 收件箱：`D:\dsh-股票\quant\logs\notifications.json`

股票路径会运行 Qlib Alpha158 + LightGBM，并检查样本外 RankIC、RankIC IR、分组多空超额收益和最大回撤。ETF 与场外基金分别输出趋势、收益、波动、回撤、相对基准和同类比较。最终组合还会检查现金下限、类别敞口、单标的权重和换手上限。

全市场抓取进行期间可通过 MCP 的 `get_rolling_scan` 读取按波次生成的股票/ETF 预备池；该结果是 preliminary，只用于观察中间进度，最终建议仍以 `get_current_snapshot` 返回的完整研究结果为准。个股回测回撤门槛按相对基准的超额回撤检查，记录字段为 `max_excess_test_drawdown`，缺少基准回撤时才使用绝对回撤上限。

## 任务计划程序

注册和注销使用：

```powershell
& 'D:\dsh-股票\tasks\register-task.ps1'
& 'D:\dsh-股票\tasks\unregister-task.ps1'
```

调度脚本具有单实例锁、30 分钟外层超时、任务级失败通知和 Windows Toast 尝试；任务计划程序本身配置为最多重试 3 次、单次最长 2 小时。研究本身的 AkShare 刷新失败、模型失败和风险门槛失败由研究状态机记录。
