# 安全边界

## 固定路径

研究服务只解析到 `D:\dsh-gupiao\quant` 下的配置、数据、Qlib provider、结果和日志。MCP 参数没有路径字段，也没有命令字段；工具不会执行任意 PowerShell 或任意 Python 文件。

## 工具面

股票 preset 只提供研究 Skill、Skill loader 和六个固定 MCP 工具，其中 `get_rolling_scan` 仅只读返回抓取期间的预备池。Web profile 的 shell、文件编辑、网页和子代理工具被禁用或不在该 preset 中。MCP 使用独立虚拟环境：

```text
D:\dsh-gupiao\quant\.venv\Scripts\python.exe
```

## 结果保护

每次运行使用独立运行 ID。成功结果通过临时文件和原子替换更新 `current.json`；失败、超时、数据质量失败和模型门槛失败均保留上一份成功快照。

## 投资决策边界

- 只输出研究和决策支持，不构成自动交易指令。
- 目标权重优先于股数，未提供真实持仓时使用假设资金并明确标记。
- 个股模型门槛失败时不生成个股买入目标权重。
- 场外基金不输出盘中价格和精确股数。
- 首期不连接券商、不读取券商账户、不自动下单。

## 受保护目录

以下目录不是本项目的写入目标：

```text
D:\deepseek-harness
C:\Users\<user>\.dsh
D:\股票基金\quant_project
```

Windows 任务计划程序的任务元数据由系统保存；项目日志、通知和运行结果仍固定写入 `D:\dsh-gupiao`。
