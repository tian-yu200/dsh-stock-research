- 没有券商连接、账户凭据、自动下单或交易执行能力。
- 场外基金只输出净值序列研究、目标权重和调仓比例，不输出盘中成交价或精确股数。
- 目标权重默认基于假设资金/配置；未提供真实持仓时不会伪装成真实账户建议。
- 当前结果和自动任务已可运行，但生产使用前仍应持续观察 AkShare 接口稳定性、模型长期样本外表现和实际组合风险。
- 完整目录和全量历史数据覆盖率分别记录；当前 `min_universe_coverage` 为 `0.93`。若全量刷新部分失败，研究会保留失败事实并按覆盖率门槛阻止不完整结果发布；抓取子进程明确 `failed` 时，即使覆盖率达标也禁止发布。
- 全市场研究按覆盖率容忍少量过期标的；定向研究只要存在过期标的即阻止发布。个股回测回撤使用相对基准的超额回撤门槛 `max_excess_test_drawdown`，缺少基准回撤时才使用绝对回撤上限。
